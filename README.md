# **THE COURSEWORK OVERVIEW**
The Self Defence Academy (SDA) is a martial arts institution. It offers disciplines such as 
Karate, Judo, Taekwondo, MMA and other styles.
Most of SDA's daily operations are managed manually. Information is recorded in different 
ways. There is no central system. This makes it hard to manage student records, classes, 
training schedules, payments and facilities.
SDA has appointed your team to develop a Self Defence Academy Management System 
(SDAMS). You must build it as a JAVA desktop application with a graphical user interface
(GUI). The solution must be designed and implemented using object-oriented programming 
(OOP) principles.
